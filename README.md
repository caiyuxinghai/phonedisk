# 随身下载盘

把手机当成联网硬盘：粘贴 http(s) 文件直链，下到手机存储，再用 USB 或同一 Wi-Fi 拷到电脑。

手机里打开 App，点右上角 **「？」** 也能看到同样的说明。

## 下载安装

1. 打开 [Releases](https://github.com/caiyuxinghai/phonedisk/releases) 下载 `PhoneDisk.apk`
2. 允许「安装未知来源应用」后安装
3. 第一次打开时按下面「使用方法」把权限给齐

这是 debug 签名包，只适合自己侧载，没有上架应用商店。

## 使用方法

### 1. 第一次打开

1. 允许**通知**（后台下载要靠通知栏进度）
2. Android 11 及以上：到「任务」页点 **去授权**，打开**所有文件访问权限**。不给的话，USB 连电脑往往看不到文件
3. 下大文件前，到「传到电脑」页点 **允许忽略电池优化**，避免系统把下载杀掉

### 2. 添加下载

1. 打开「任务」，点右下角 **+**
2. 粘贴 **文件直链**（浏览器里点下去会直接开始下文件的那种 `http://` / `https://` 地址）
3. 文件名可留空，一般会从链接里自动猜
4. 建议勾选 **仅 Wi-Fi 下载**，避免用手机流量下几个 GB
5. 点「开始」。可暂停、继续、取消；网络中断后点继续，服务器支持断点时会接着下

判断是不是直链：用电脑浏览器打开这个链接，如果马上开始下载文件，就可以贴进来。如果打开的是网页、登录页、Steam 商店页，就不是。

### 3. 下完以后拷到电脑

**方法 A：USB（推荐）**

1. 数据线连接手机和电脑，手机选「传输文件 / MTP」
2. 电脑里打开手机存储 → `Download` → `PhoneDisk`
3. 把文件复制到电脑硬盘

**方法 B：同一 Wi-Fi**

1. 手机和电脑连**同一个 Wi-Fi**（不要用手机热点给电脑，也不要公共免费 Wi-Fi）
2. 打开 App「传到电脑」，打开 **局域网服务**
3. 在电脑浏览器输入屏幕上的地址，例如 `http://192.168.x.x:8765`
4. 点文件名即可拷到电脑
5. 用完把开关关掉

## 注意事项

- **不能下 Steam / Epic / 战网游戏库。** 商店页、社区页都不是文件地址，贴进去会失败。游戏必须用电脑上的官方客户端下。
- **只支持 http(s) 直链。** 不支持磁力、BT、需要登录才能解析的网盘分享页。百度网盘、阿里云盘的分享链接一般也不行，除非你拿到了真正的文件直链。
- **大文件很占空间和流量。** 下载前看一眼手机剩余存储。默认「仅 Wi-Fi」请不要随便关掉。
- **直链失效、要登录、或返回网页时会失败。** 这是正常的，换一个真正能直接下载的地址。
- **不是所有网站都支持断点续传。** 不支持的话，中断后只能从头再下。
- **局域网取文件没有密码。** 同一 Wi-Fi 里别人也可能打开那个地址。只在家里用，用完即关。
- **系统可能杀后台。** 长时间下载请充电、关掉电池优化，并保留通知权限。
- **这是未上架的测试包。** 手机可能会提示「未知来源 / 不安全」。这是侧载都会有的提示，请只从本仓库的 Releases 下载，不要从别人转发的来路不明的文件安装。
- **卸载前先把文件拷走。** 如果当时没给「所有文件访问」，文件可能在应用私有目录，卸载会一起删掉。

## 自己编译

需要 JDK 17 和 Android SDK（compileSdk 35）。

```bat
set JAVA_HOME=C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot
gradlew.bat assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`
